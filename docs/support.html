Help & Support

Need help with MINDMATCH, found a bug, or have a suggestion? Contact the project team through the official GitHub support channel.

Contact support

Open a support request on the MINDMATCH GitHub repository. The issue tracker is public, so do not include personal data, passwords, private messages, or challenge codes.

Open a support request

Helpful details to include

  • Your device model and Android version.
  • The MINDMATCH app version.
  • A short description of what happened and steps to reproduce it.
  • A screenshot only after removing personal or sensitive information.

For privacy questions, see the Privacy Policy.
